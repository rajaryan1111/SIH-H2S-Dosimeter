# Security Policy

## Scope

This project is a Smart India Hackathon prototype. Do not submit real worker identities, occupational-health records, credentials, production database dumps, or other sensitive data to the public repository.

## Reporting a vulnerability

Please report security issues privately through the maintainer's GitHub profile rather than opening a public issue. Include the affected component, reproduction steps, and potential impact.

## Sensitive configuration

Keep database credentials, JWT secrets, API keys, and deployment configuration in environment variables. Never commit real credentials or private worker data.

The repository's demo and ML evaluation data are not a substitute for production occupational-health validation.
